**This build is not notarized by Apple yet**, so macOS will block the first launch. To open it:

1. Open Tallshot. When macOS says it can't check it, click **Done**.
2. Open **System Settings → Privacy & Security**, scroll down, and click **Open Anyway** next to the Tallshot message.
3. Confirm, then click **Open**. You only do this once.

Prefer to build it yourself? `git clone https://github.com/garoknows/tallshot && cd tallshot && scripts/install.sh` (needs Xcode).
